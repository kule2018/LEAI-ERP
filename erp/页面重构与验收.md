# LEAIerp 页面重构与验收

LEAIerp 是面向商贸和轻制造企业的一体化 ERP。业务链覆盖销售、采购、库存、生产计划、财务、人事、协同和商城，打印中心与 AI 助手提供跨模块能力。桌面端为 Vue 3 / Vite，接口服务为 NestJS / MySQL，仓库也包含 UniApp 移动端。

页面范围以两份 ERP 产品文档和当前菜单为准。桌面端 13 个模块共有 265 个菜单路由，包含 5 个隐藏入口。每个路由配置一个独立组件。登录页与兜底跳转单独配置。页面可以复用按钮、表格、表单和导入组件，业务页面自行指定字段、筛选、数据地址及操作。

## 业务入口

| 业务域 | 重构后的入口和数据 |
|---|---|
| 销售客户 | 清单销售、新建、编辑、批量导入独立。销售明细、汇总及排行接正式订单查询接口；演示模式保留报表种子数据。 |
| 采购供应 | 采购订单使用正式订单列表和状态接口，批量导入在同一账套生成草稿。原采购履约台保留单独入口，沿用其原有数据来源。采购明细、汇总及历史价查询已确认订单和行明细。 |
| 库存仓储 | 产品创建、导入新增、按编码更新、Code 128 条码打印各有入口。负库存查询使用实时余额。退料入库、其他出入库提供记录查询和后续入口。 |
| 生产制造 | 生产计划、工序甘特、负荷、齐套、排产预警划分为五页。工作中心日历与排产记录可独立访问。 |
| 财务结算 | 新建支出、收入各自录入草稿并返回对应列表。损益表接会计接口。财务仪表盘、资产负债表、税务汇总仍查询现有快照表。 |
| 协同、人事、商城和系统 | 文档中原来落到通用页的入口按字段和操作改造。报表、日志、同步历史可查询和导出本页，主数据维护及受支持的业务动作单独配置。 |
| AI 和开放平台 | 文字智能建单通过主数据匹配和人工核对创建销售草稿。OCR 单独上传识别、核对与复制结果。Webhook 日志独立查询推送记录。 |

## 验收范围

- 检查菜单路由和页面组件一一对应，页面组件文件均存在。
- 编译检查 Vue 模板和 TypeScript 源文件。使用现有 Vue/Vite 依赖离线检查前端模块。依赖缓存缺少部分第三方库，离线打包时将这些库设为外部依赖。
- 运行演示数据验证，包括 49 个重构列表、带引号和换行的 CSV、产品重复校验、仅更新、销售及采购草稿、采购导入记录、APS 排产、齐套、产能及 Webhook 模拟日志。
- 正式 MySQL、Redis、真实条码打印、外部商城回传和视觉模型 OCR 待联调。现有资产负债、报税、商城同步等快照或历史页只展示项目已有数据。文档中尚未接入的线索转化的独立界面、银企直连和税务直连等功能另需对应业务实现和环境。

## 本地运行

工作区已补充项目原来引用的共享包及 pnpm 工作区配置。安装 Docker、Node.js 和 pnpm 后，在项目根目录执行。

```bash
pnpm install
pnpm dev:web
```

打开 [http://localhost:5173](http://localhost:5173)，可以使用登录页的「使用演示数据」进入。正式模式需先部署 MySQL 和 Redis，在目标数据库按编号初始化对应的 `sql/` 文件，配置 `apps/server/.env`，然后运行 `pnpm dev:server`。配置项见各应用的 `.env.example`。
